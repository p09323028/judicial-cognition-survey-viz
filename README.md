# 一般民眾對司法認知調查 110–114 年：互動式視覺化

## 開啟方式
直接雙擊 `index.html`，用 Chrome 或 Edge 開啟即可。所有函式庫和資料都在本資料夾內，**不需網路、不需架伺服器**，可在內網使用。

複製或搬移時，請保持整個 `Visualization` 資料夾的結構完整。

## 內容
| 區塊 | 說明 |
|---|---|
| 總覽 | 信任法官、願意上法院、曾到過法院、到法院整體滿意度的 KPI 卡，可切換年度 |
| 年度趨勢 | 6 項指標的 5 年折線圖，以及單一指標的回答分布（分歧堆疊圖） |
| 族群比較 | 依年齡、教育、性別、訪問語言切分，附 95% 信賴區間與全體平均參考線 |
| 縣市比較 | 台灣縣市方格地圖；點選縣市可看 5 年趨勢，另有可排序的資料表 |
| 法院使用經驗 | 使用階段比例、開庭滿意度、法院服務滿意度、不願上法院原因、去過法院後觀感、資訊管道、法律常識答對率 |
| 調查說明 | 樣本數、權重與閱讀注意事項 |

每張圖下方都有「顯示資料表」可查看數字。右上角按鈕可切換深色／淺色模式。

## 更新資料（例如加入 115 年）
1. 把新年度資料放到上一層，例如 `../115/data115.dta`。
2. 在 `build_data.py` 的 `YEARS` 加入 `"115"`，並在 `MAP` 加入該年題號對照（參考 114 年；各年題號、權重變數名稱可能不同）。
3. 執行：
   ```
   python build_data.py
   ```
   需要 Python 與 pandas、numpy。網頁會自動讀取新的年度。

## 估計方式
- **正面比例**：非常＋還算的加權比例，分母排除「無意見／拒答」。因此會比官方報告（分母含無意見）高 1–3 個百分點。
- **回答分布圖**：保留無意見類別，可與報告直接對照。
- **權重**：110–113 年用 `wgat_t1`，114 年用 `wgat_t2`。
- **信賴區間**：95% 信賴區間，以 Kish 有效樣本數計算。
- **核對結果**：
  - 110、113 年的回答分布與官方報告一致。
  - 114 年以公開資料檔權重計算，與報告約差 1 個百分點（例如信任法官 60.8% vs. 報告 59.8%），原因可能是報告使用的權重和公開檔不同。
- 題目措辭變動、樣本年齡範圍等注意事項，列在網頁「調查說明」區。

## 設計
- 依 ui-ux-pro-max「Accessible & Ethical」風格：高對比、可鍵盤操作、清楚的焦點框、尊重「減少動態」設定。
- 圖表配色經 dataviz 色盲與對比檢查。系列以顏色＋線型＋直接標註區分，不只靠顏色。
